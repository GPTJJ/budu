# 美团餐饮开放平台接入指南（M4）

> 目标：每 5 分钟拉取已授权门店的营业数据（营业额/订单/渠道/退款/菜品），
> 写入 PostgreSQL 并映射到首页、数据分析、商品销售、财务板块。

## 1. 申请与授权（用户操作）

1. 注册/登录美团餐饮开放平台（https://open-erp.meituan.com 或美团餐饮商家后台的开放平台入口）
2. 创建应用，获取 `app_id` 与 `app_secret`
3. 在应用里添加需要对接的门店（商家授权），记录每个门店的 **美团店铺 ID**
4. 配置服务器出口 IP 白名单（当前服务器公网 IP：`124.156.171.195`）
5. 将凭证写入服务器 `/opt/budu/.env.production`：
   ```
   MEITUAN_ENABLED=1
   MEITUAN_APP_ID=你的app_id
   MEITUAN_APP_SECRET=你的app_secret
   ```

## 2. 系统侧配置

1. 开发者登录系统 → 系统设置 → **美团收银对接**
2. 添加「美团店铺ID → 系统门店」映射（可多店）
3. 点击「立即同步」验证一次（未配置凭证时为模拟模式，只返回样例、不写库）
4. 配置 `MEITUAN_API_BASE` / `MEITUAN_ORDER_API`（如官方接口域名/路径不同，在服务器环境变量调整）

## 3. 数据口径

- 美团数据写入 `DailySales`（营业额/订单/退款/渠道）与 `DishDaily`（菜品）
- 同日有手工录入时：**美团覆盖营业额/订单/渠道，手工值班人员保留**（工资计算不受影响）
- 菜品按名称自动匹配系统商品；未匹配的进入「菜品待匹配」清单，开发者建映射后自动并入商品销售 TOP
- 退款计入 refundCents，展示在首页/财务，不自动扣库存

## 4. 常见问题

- 同步日志显示失败：多为接口地址/签名不匹配或返回字段不同，把日志里的 message 发给开发调整
- 签名规则：默认按「appSecret + 排序参数串 + appSecret」MD5 大写（`server/meituan/sign.js`），以官方文档为准
- 凭证错误：确认 app_id/app_secret 正确、门店已授权、服务器 IP 已加白名单
