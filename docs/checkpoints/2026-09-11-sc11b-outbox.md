# G3 financial transaction and durable mirror foundation

Candidate implementation, NOT end-to-end integration certification.

Decision: every financial envelope/version change through
`onlineFinancialTransaction` inserts an immutable outbox snapshot in the same
Serializable PG transaction. New settlement starts version1; changed envelope
requires exactly next version. DB-only retry handles proven serialization aborts;
unknown commit outcomes never blindly retry. Lock order remains settlement then
account. Existing facts recover independently of purchase flags.

Outbox worker atomically leases one due event with SKIP LOCKED. Fresh fencing
identity on each lease; DB clock controls expiry and backoff. A previous worker
cannot acknowledge or clear its successor lease. Delivery is at-least-once;
only exact eventKey/version plus APPLIED/ALREADY_APPLIED/SUPERSEDED ack marks
success. Network/raw errors become fixed safe classification; financial facts
never revert on transport failure. Transport is bounded at10sec.

callback and reading prior version from that snapshot. Added compensation summary
to safe envelope. No raw provider credential/transaction/payer/recipient data in
mirror snapshot. Monetary values are integer-cent strings.
