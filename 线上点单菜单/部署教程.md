# 微信线上菜单 · 发布教程

这个文件夹里有两个文件：

- `线上菜单.html`：顾客看到的点单页（手机电脑都能打开，不需要安装任何软件；店名是 budu，微信二维码已内嵌在页面里）
- `部署教程.md`：你现在看的这份说明

页面本身**不收款、不接后台**。顾客选好商品、填好收件信息后，页面会生成一段订单文字，顾客一键复制，粘贴发到你的微信即可。

顾客在页面上方能看到「扫码添加商家微信」卡片，扫码添加后，把复制的订单发到那个微信就行。

---

## 方法一：Vercel（推荐）

1. 打开 [vercel.com/new](https://vercel.com/new)，用邮箱或 GitHub 免费注册登录。
2. 点击页面上传入口（Upload / 上传），把 `线上点单菜单` 文件夹直接拖进去。
3. 等十几秒，会得到一个链接，例如 `https://你的项目名.vercel.app`。
4. 把这个链接发给微信顾客，点开就能下单。

> 小技巧：上传前把 `线上菜单.html` 改名为 `index.html`，链接末尾就不用带文件名，分享时更短。

---

## 方法二：Netlify Drop（最简单）

1. 打开 [app.netlify.com/drop](https://app.netlify.com/drop)，用邮箱免费登录。
2. 把 `线上点单菜单` 文件夹（或里面的 HTML 文件）拖进页面。
3. 马上会得到一个 `https://xxxxx.netlify.app` 链接，可以立即分享。

---

## 方法三：GitHub Pages（适合长期维护）

1. 注册 [github.com](https://github.com) 并新建一个仓库（Repository），名字随意，比如 `menu`。
2. 把 `线上菜单.html` 上传到仓库（建议改名为 `index.html`）。
3. 打开仓库的 **Settings → Pages**，Source 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
4. 等一两分钟，链接变成 `https://你的用户名.github.io/menu/`。

## 在微信里使用的小提示

- 微信内置浏览器可以直接打开这些链接，正常浏览、加购、复制订单。
- 想让顾客扫二维码下单：把链接复制到 [草料二维码](https://cli.im) 生成二维码，打印出来放店里，顾客扫码就能点。
- 页面更新后顾客可能看到旧内容：让顾客在微信里长按链接重新打开，或右上角刷新。
- 如果复制按钮提示失败：让顾客**长按订单文字**，手动选择“复制”，再粘贴发送即可。
- 顾客不需要注册、不需要付款，也看不到你的手机号，只有你收到订单文字后才会私下联系。

## 怎么改店名、价格、加图片

用记事本或任意文本编辑器打开 `线上菜单.html`，滚动到文件靠前的 `<script>` 部分：

- **改店名和微信号**：修改 `SHOP` 里的 `name` 和 `wechat` 两行文字（当前店名是 budu）。
- **改价格或删除商品**：在 `MENU` 列表里改 `price` 数字，或整行删掉不要的商品。
- **加菜品照片**：在对应商品行里加 `img: "图片地址"`，例如 `img: "https://example.com/photo.jpg"`。填好后该商品会自动显示照片。
- **换微信二维码**：页面里的二维码已经以图片数据的形式写进文件。换码时，把新二维码图片转成 base64 文本，替换 `QR_IMG` 引号里的内容（`data:image/jpeg;base64,` 后面那一大段）。也可以用工具网站（如 base64.us）完成转换，或者直接把新图片发给我，我来替换。

改完保存，再按上面的方法重新上传一次即可。
